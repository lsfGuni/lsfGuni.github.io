"제 컴퓨터에서는 잘 돌아가는데요."

인프라 일을 하면서 가장 자주 들은 말입니다. 예전 회사에서도 비슷한 일이 있었습니다. AI로 빠르게 만든 서비스가 개발자 노트북에서는 아무 문제 없이 돌아갔습니다. 그런데 이걸 여러 사람이 쓰는 서비스로 운영하려면 클라우드 비용이 나가고, 사내 서버로 구축하면 장비만 2억 원이 넘는다는 계산이 나왔습니다. 돌아온 반응은 이랬습니다.

"로컬에서 잘 되는데, 왜 돈이 들어요?"

그때는 답답했습니다. 지금 돌아보면 그건 틀린 질문이 아니었습니다. **아무도 제대로 설명해 주지 않은 질문**이었습니다. 이 글은 그때 하지 못한 설명입니다.

## 로컬과 운영은 다른 세계입니다

내 컴퓨터에서 서비스를 돌린다는 건 이런 상태입니다.

- 쓰는 사람이 **나 한 명**입니다
- 모든 것이 **내 폴더 안**에 있습니다
- 나는 **모든 권한**을 가진 관리자입니다
- 꺼져도 **아무도 모릅니다**

운영 환경은 정반대입니다. 모르는 사람이 동시에, 하루 24시간 접속합니다. 그중에는 나쁜 의도를 가진 사람도 있습니다. 그리고 꺼지면 장애입니다.

같은 코드라도 이 차이를 견디게 만드는 데 일과 비용이 듭니다.

## 무엇이 달라지는가

| | 내 컴퓨터 | 운영 환경 |
|---|---|---|
| 접속 | `localhost`로 나만 접속 | 도메인, DNS, HTTPS 인증서가 필요 |
| 사용자 | 1명 | 동시에 여러 명, 몰리면 서버를 늘려야 함 |
| 보안 | 내가 관리자 | 로그인, 권한, 비밀키 관리, 서비스 간 격리 |
| 연결 | 한 컴퓨터 안에서 끝남 | 여러 서비스가 네트워크로 연결되고, 서로 인증해야 함 |
| 지속성 | 꺼도 그만 | 감시, 알림, 백업, 복구가 필요 |
| 재현성 | 내 폴더에서만 됨 | 언제든 똑같이 다시 만들 수 있어야 함 |

마지막 줄이 특히 중요합니다. 내 폴더에서 되는 것은 "내 폴더에서 된다"는 것만 증명합니다. 서버가 망가졌을 때 같은 환경을 다시 만들 수 없다면, 그 서비스는 운이 좋아서 돌아가고 있는 것입니다. 그래서 운영 환경은 Terraform 같은 도구로 인프라를 코드로 남기고, 배포를 자동화합니다.

## 비용은 '서버값'이 아니라 '보장값'입니다

운영 비용을 서버 임대료로만 보면 비싸 보입니다. 하지만 실제로 돈을 내는 대상은 이런 보장입니다.

- 모르는 사람이 들어와도 **내 데이터가 안전하다**
- 사용자가 몰려도 **서비스가 버틴다**
- 서버가 죽어도 **다시 살릴 수 있다**
- 담당자가 바뀌어도 **누군가 이어받을 수 있다**

이 보장이 필요 없는 단계라면 돈을 쓸 필요도 없습니다. 혼자 테스트하는 단계에서는 무료나 저렴한 호스팅으로 충분합니다. 문제는 실제 사용자를 받기 시작했는데 여전히 "내 컴퓨터에서는 된다"는 기준으로 판단할 때 생깁니다.

## 바이브코딩 시대에 더 중요해진 이유

AI는 코드 안을 정말 잘 봅니다. 기능은 이제 며칠 만에 만들어집니다.

하지만 AI는 **코드 밖**을 보지 못합니다. 도메인을 사서 연결하는 일, 클라우드 콘솔에서 권한을 설정하는 일, 서버에만 있어야 할 비밀키를 관리하는 일은 코드 바깥에 있습니다. 그리고 여기서 막히면 무엇을 물어봐야 할지조차 모르게 됩니다. "DNS를 설정하세요"라는 안내가 외국어처럼 읽히는 순간입니다.

코드가 빨리 만들어질수록, 이 간극도 더 빨리 드러납니다. 예전에는 개발 기간이 길어서 그사이 누군가 인프라를 준비했습니다. 이제는 기능이 먼저 완성되고, 인프라 질문이 한꺼번에 몰려옵니다.

## 정리하면

"로컬에서는 되는데 왜 돈이 드나요?"라는 질문에 저는 이제 이렇게 답합니다.

> 로컬에서 된다는 건 **나 혼자, 내 컴퓨터에서, 지금** 된다는 뜻입니다. 운영은 **모르는 사람이, 동시에, 계속** 써도 된다는 뜻입니다. 그 차이를 보장하는 데 비용이 듭니다.

그리고 그 비용을 얼마나, 언제부터 쓸지는 서비스 단계에 맞춰 정하면 됩니다. 처음부터 비싸게 시작할 필요는 없지만, 실제 사용자를 받기 전에는 최소한 확인해야 할 것들이 있습니다.

다음 글에서는 바이브코딩으로 만든 서비스를 출시하기 전에 꼭 확인해야 할 다섯 가지를 정리하겠습니다.
