# 블로그 글 쓰는 방법

## 1. 파일 위치와 이름

`blog/_posts/` 폴더에 아래 형식으로 파일을 만듭니다.

```
blog/_posts/2026-11-20-글-주소에-쓸-영문-또는-한글.md
```

- 날짜(YYYY-MM-DD)가 파일 이름 앞에 꼭 있어야 글로 인식됩니다.
- 공개하기 전 초안은 `_drafts/` 폴더에 두면 사이트에 올라가지 않습니다. 공개할 때 `blog/_posts/`로 옮기고 파일 이름 앞에 날짜를 붙입니다.

## 2. 파일 맨 위에 붙일 머리말

```yaml
---
layout: post
title: "글 제목"
subtitle: "부제 (없으면 이 줄 삭제)"
categories: [blog]
tags: [바이브코딩, 인프라]
comments: false
---
```

- `categories: [blog]`가 있어야 Blog 목록에 나옵니다.
- 머리말 아래부터 본문을 마크다운으로 씁니다.

## 3. 올리는 방법

- **Claude에게 맡기기:** "이 내용으로 블로그 글 올려 줘"라고 하면 브랜치와 PR을 만들어 줍니다.
- **집 PC 브라우저:** GitHub 저장소 화면에서 `.` 키를 누르면 웹 편집기가 열립니다. 파일을 만들고 커밋하면 몇 분 뒤 사이트에 반영됩니다.
